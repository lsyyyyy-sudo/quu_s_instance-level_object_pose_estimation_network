## 01 数据集 v1 的图

### `v1_fullframe_gt_projection.jpg`
三帧**整帧 v1 渲染**的标注可视化。**绿框** = 目标实例的 `bbox_visib`；**红圈** = 目标 8 个角点按 GT
位姿投影；**灰框** = **其他同类实例**（`bbox_obj`）。每帧顶部标了 `gb_idx / box / visib px`。

**看点**：
1. 画面里**每一个物体都是同一款 DJI**（灰框全是 DJI）—— 这是 `DATA-27` 最直观的可视化证据
2. 红圈确实落在物体角上 → 标注本身是对的

### `v1_crop_corners_heatmap.png`
三组「**256×256 裁剪 + 8 角点（黄，编号 1-8）**」并排「**8 通道热图的最大值投影**」。
标题带样本下标（`#0 / #1656 / #3312`）。

**看点**：热图峰值与角点一一对应 ⇒ **标签管线（投影 → 热图）是正确的**。
另外注意裁剪图里**混着别的 DJI** —— 这是"1.4× 裁剪框内 96.2% 含其他同类实例"的样子。

## 02 数据集 GEO7 的图

### `geo7_scene000000_f0000.png` / `geo7_scene000001_f0001.png` / `geo7_scene000002_f0002.png`
GEO7 渲染预览（三张来自不同场景）。多台 DJI 摆在浅色平面上（GEO7 无料箱），**屏幕内容随机** ——
有一台显示彩色渐变画面，其余显示相机菜单界面。

**看点**：屏幕内容随机化是 GEO7 相对 v1 的关键改动之一（让模型学"那是屏幕"而不是背纹理）。

### `geo_series_static_cover_with_gt.jpg`
四帧，**带 GT 3D 框投影**（绿框 = 3D 盒、红叉 = 8 角点、黄线 = 盒棱）。
注意这是 **GEO6**（静态压盖实验）而不是 GEO7 —— GEO7 的预览没有画 GT 框。

**看点**：能看到**异类 Objaverse 道具**（相机状物体、带花纹的方块）静态压在 DJI 上造遮挡。
这是"造遮挡"唯一成功的做法（料箱堆叠那版造出大量无解样本，见 `docs/RESULTS.md` §11）。

## 03 v1 模型在数据集上的效果

### `v1_best4_worst4.png`
2 行 × 4 列，橙线框 = 预测的 8 角点，标题给 `err(px) / visb`。

| | 误差 | `visib_fract` |
|---|---|---|
| **上排 BEST 4** | 1.0 / 1.0 / 0.7 / 0.7 px | 全部 **1.00** |
| **下排 WORST 4** | 141.9 / 88.3 / 77.8 / 71.7 px | **0.25 / 0.25 / 0.29 / 0.24** |

**看点（这张图是整个项目的出发点）**：**失败全部集中在严重遮挡的样本上**。
配合 `docs/PROJECT_SUMMARY.md` §3.1 的分层统计（完全可见失败率 0.79% vs 严重遮挡 45%，**差 57 倍**），
说明根因是"训练集 90% 完全可见 ⇒ 模型从没学过外推被挡住的角点"。

## 05 GEO7 模型在数据集上的效果

### `geo7_best4_worst4.png`
同 `03` 的格式。

| | 误差 | `visib_fract` |
|---|---|---|
| **上排 BEST 4** | **1.8 / 2.3 / 5.0 / 5.1 px** | 全部 1.00 |
| **下排 WORST 4** | **206 / 195 / 194 / 150 px** | 0.36 / **1.00 / 1.00** / 0.25 |

**看点（与 v1 对比着看）**：
1. **连最好的样本都比 v1 差 2~5 倍**（1.8 vs 1.0 px）⇒ GEO7 是**整体**变差，不只是难样本
2. **WORST 里有 2 个 `visb=1.00`（完全可见）** ⇒ **GEO7 的失败不只是遮挡**
3. 整体变差的原因见 §3.3 的排名反转：GEO7 用随机资产/屏幕/色温逼模型学几何，牺牲了合成集分数

## 一句话怎么用这套图

```
01 → 数据长什么样、标注对不对、以及"每帧全是同一款 DJI"这个设计缺陷
02 → 数据的外观多样性改造（随机屏幕内容、异类道具压盖）
03 + 05 → 模型在合成集上的强弱项（失败集中在遮挡 / GEO7 整体变差）
04 + 06 → 真实视频上的效果，以及"合成集最好 ≠ 真实最好"的排名反转
07 → 多实例路线在真实视频上的现状
```
